Printing the Source Code

Prepare to Print

  1. Load the source code file into Quincy's editor.
  2. Select the source code file as the active window.
  3. Choose the Print Setup command on the File menu to select and setup your printer. This command opens the Print Setup dialog shown here.

  4. If you want line numbers printed with the source code listing, check the Print Line Numbers checkbox on the Print Setup dialog.
  5. click OK when your printer is setup correctly.

Print Preview

  1. Click the Print Preview button.

  2. Or choose the Print Preview command on the File menu to display an image of the printed page as shown here.

  3. Click anywhere in the displayed page to zoom in.
  4. Click several times for more zooms and, eventually, to zoom out to the original display.
  5. Click the Close button when you are finished previewing the printed document.

    Print the Source Code Listing

    1. Click the Print tool button.

    2. Or choose the Print command on the File menu.

      These commands open the Print dialog shown here.

    3. You get another chance to select a printer and whether you want line numbers printed.
    4. Click OK to print the source code listing.
