Quincy is an integrated development environment (IDE) for C or C++.
It works under Windows 32 (including with Vista from version 1.3)

Quincy combines a programmer's editor, compiler, debugger and other development tools into one 32-bit Windows application. Quincy uses the MinGW port of the GCC compiler system.

Quincy 2005 is open-source freeware and is released without any licencing restriction.
Quincy 2005 is based on Al Stevens' Quincy 2002 IDE. Quincy 2002 is also open source freeware and was released without any licencing restriction whatsoever, see http://www.alstevens.com/quincyfaq.html

This release includes the following components:

	See http://quincy.codecutter.org
